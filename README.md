# Alberto Jaenal Gálvez - Personal Website

Personal website for Dr. Alberto Jaenal Gálvez, Juan de la Cierva Postdoctoral Researcher at the University of Zaragoza.

## Website Structure

- **Home**: Introduction and research interests
- **About**: Detailed biography and academic background
- **Publications**: Complete list of publications (journals, conferences, book chapters)
- **Teaching**: Teaching experience and student supervision information

## Building the Site Locally

The site is built with Jekyll and hosted on GitHub Pages.

```bash
cd docs
bundle install
bundle exec jekyll serve
```

Then visit `http://localhost:4000` in your browser.

## Deployment

The site is automatically deployed to GitHub Pages when changes are pushed to the main branch.
